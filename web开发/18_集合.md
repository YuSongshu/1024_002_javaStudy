集合可以多个数据容器，和数组作用一样的

#### ArrayList

简述：java中一个类，可以动态存储数据，是基于数组实现的

优点：长度是动态的，索引，访问数据性能比较快的 

缺点：调整大小的性能开销，插入效率和删除效率比较慢 

**重点：默认创建长度为10数组，按照当前1.5倍进行扩容**

##### 遍历

1.

```
for (int i = 0; i < 集合名.size();i++){
    System.out.println(集合名.get(i));
}
```

2.加强for

```
for (泛型类型 临时变量名:集合名){
	System.out.println(临时变量名);
}
```

3.迭代器 Iterator

```
Iterator<泛型类型> it = 集合名.iterator();
while (it.hasNext()){
    泛型类型 临时变量名 = it.next();
    System.out.println(临时变量名);
}
```

4.Lambda forEach

```
集合名.forEach((泛型类型 临时变量名) -> {
    System.out.println(临时变量名);
});

集合名.forEach(临时变量名 -> System.out.println(临时变量名));
```





示例

```
import java.util.ArrayList;
import java.util.HashSet;
import java.util.Iterator;
import java.util.Set;

public class TestForeach {
    public static void main(String[] args) {
        ArrayList<String> list = new ArrayList<>();
        list.add("张三");
        list.add("李四");
        list.add("王五");

        System.out.println("===== 1.普通for循环（只有List能用，有下标）=====");
        for (int i = 0; i < list.size(); i++) {
            System.out.println(list.get(i));
        }

        System.out.println("===== 2.增强for循环（List、Set通用）=====");
        for (String s : list) {
            System.out.println(s);
        }

        System.out.println("===== 3.迭代器遍历（List、Set通用，可边遍历边删除）=====");
        Iterator<String> it = list.iterator();
        while (it.hasNext()) {
            String s = it.next();
            System.out.println(s);
        }

        System.out.println("===== 4.Lambda遍历（最简，开发常用）=====");
        list.forEach(s -> System.out.println(s));


        // ========== Set 演示（只能用后三种）==========
        System.out.println("\n========== Set 遍历 ==========");
        Set<String> set = new HashSet<>();
        set.add("小明");
        set.add("小红");

        // 增强for
        for (String s : set) {
            System.out.println(s);
        }

        // 迭代器
        Iterator<String> it2 = set.iterator();
        while (it2.hasNext()) {
            System.out.println(it2.next());
        }

        // Lambda
        set.forEach(s -> System.out.println(s));
    }
}
```





#### LinkedList

简述：java中一个类，可以动态存储数据，基于双向循环链表实现结构

优点：插入，删除很快

缺点：查询数据的相对较慢（隐式索引）



##### 创建

LinkedList<泛型> 集合名 = new LinkedList<>();

示例

```
LinkedList<Double> list = new LinkedList<>();
```



##### 增删改查

与 ArrayList 类似

```
add(index,元素)、remove(index)、set(index,元素)、get(index)
```









#### Stack

栈：数组实现的 

特点：LIFO（后进先出）



常用方法

push(e)：入栈 —— 把 e 放到栈顶

pop()：出栈 —— 移除并返回栈顶；空栈抛异常

peek()：取栈顶 —— 只看不移除

isEmpty() / empty()：判空

size()：元素个数







#### 应用

java程序之中缓存数据，查询非常频繁地，用ArrayList

频繁修改内部数据，用LinkedList







#### 总结

ArrayList

有下标所以索引很快，但插入会改变插入下标之后的所有元素的下标所以会很慢



LinkedList

元素之间靠**节点指针 / 引用**把元素串成逻辑上的线性序列

Java 的 `java.util.LinkedList` 是**双向链表**

所以增删快（只需改指针），查询慢（必须从头遍历）



Stack

栈（Stack）是 “后进先出 LIFO” 的线性表，只在一端（栈顶）做插入 / 删除

### Set接口



- 系列集合之中，添加元素无序，不重复，无索引 
- 无序：不等于随机
- HashSet:底层哈希表实现到的结构，存储数据，计算数据哈希值，存储哪里 ，扔掉 
- TreeSet：底层红黑树，存储比较数据大小，默认排序 ，扔掉 



#### HashSet

底层哈希表实现

jdk1.8之前：数组 + 链表 

jdk1.8之后：数组 + 链表  + 红黑树 

特点：set集合是无序的，不会有重复数据

作用：数据去重 （原理：哈希值不允许重复）

哈希值：对象的整数表现形式 

如果自定义类型自动去重，重写hashCode + equals



##### 创建

Set<泛型> 集合名 = new HashSet<>();

示例

```
Set<String> set = new HashSet<>();
```



##### 增

 集合名.add(元素)

无序，故非尾部添加

```
list.add("第一个数据");
```





##### 删

 集合名.remove(元素)				返回boolean，删除成功返回true，失败为false即没有该元素



##### 判断是否包含元素

 集合名.contains(元素)

```
// 调用集合对象 set 的 contains 方法，判断是否包含"李四"，返回布尔值
boolean bol = set.contains("李四");
```



##### 遍历

类 ArrayList ，但只能用2.3.4.



HashSet：哈希表，（数组 + 链表 + 红黑树），数据自动去重 ，自己写的类，必须手动重写 hashCOde Equals方法 



#### TreeSet

本质：有序、去重、基于红黑树（自平衡 BST）的 Set

TreeSet = 自动排序 + 自动去重 + 增删查 O (log n)。

无索引：不能随机访问（get (index) 不存在）



##### 创建

Set<泛型> 集合名 = new TreeSet<>();

示例

```
Set<String> set = new TreeSet<>();
```



方法都一样



##### 对比

| 特性       | TreeSet                   | HashSet           |
| ---------- | ------------------------- | ----------------- |
| 底层       | 红黑树（TreeMap）         | 哈希表（HashMap） |
| 排序       | 有序（自然 / Comparator） | 无序              |
| 去重依据   | compare/compareTo == 0    | equals + hashCode |
| 时间复杂度 | O(log n)                  | O (1) 平均        |
| 适用       | 要排序、范围查询          | 只去重、追求快    |







## Map体系



双列集合特点：

- 一次添加数据一对 key value
- 键不可以重复，但是value可以重复 
- 键和值一一对应的，键 找到 值 



与python字典类似



### HashMap

是一个类，Map接口下实现类

底层：哈希表实现（jdk1.7 数组 + 链表） jdk1.8 ： 数组 + 链表 + 红黑树 结构 

特点：无序，无索引，键不重复，可以键数据去重 



#### 创建

HashMap<泛型,泛型> 集合名 = new HashMap<>();

```
HashMap<String,String> map = new HashMap<>();
```



#### 增

集合名.put(key,value)

返回值：这个键之前对应的旧值，如果键是第一次新增，返回 null

```
map.put("第一个数据","张三");
```



#### 删

1.根据键删除：集合名.remove(key)

返回值：被删掉的 value，不存在返回 null

```
map.remove("第一个数据");
```



2.键值都匹配才删除：集合名.remove(key, value);

返回值：boolean ，删成功返回 true，否则 false

```
map.put("第一个数据","张三");
map.put("第er个数据","李四");
map.put("第一个数据","王五");
boolean bol = map.remove("okle","测试");
System.out.println(bol);
```

输出

```
false
```



### TreeMap

键自动排序：默认自然排序（数字升序、字母字典序）

键不能为 null（会空指针），值可以 null

非线程安全

#### 常用方法



```
put(key, value)       // 增/改，返回旧值
get(key)               // 查
remove(key)            // 删
containsKey(key)       // 是否包含键
size() 					// 大小
clear()      		   // 清空
```

TreeMap 特有

```
firstKey()             // 最小键
lastKey()              // 最大键
firstEntry()           // 最小键值对
lastEntry()            // 最大键值对

subMap(a, b)           // [a, b) 区间子map
headMap(b)             // < b 的所有
tailMap(a)             // >= a 的所有
```



### 对比

HashMap：**无序、快、O (1)**

TreeMap：**有序、稍慢、O (log n)**

| 特性    | HashMap        | TreeMap                         |
| ------- | -------------- | ------------------------------- |
| 顺序    | 无序           | 按键升序                        |
| 底层    | 哈希表         | 红黑树                          |
| null 键 | 允许 1 个      | ❌ 不允许                        |
| 速度    | 快 O (1)       | 稍慢 O (log n)                  |
| 适用    | 存了就取、无序 | 要排序、要最大 / 最小、范围查询 |
