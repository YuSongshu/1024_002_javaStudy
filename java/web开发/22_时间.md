# 22_时间

Java8下时间

类型：LocalDate，LocalDateTime，LocalTime

## 获取日期

LocalDate.now()

```
LocalDate date = LocalDate.now();
```

## 获取 日期+时间

LocalDateTime.now()

```
LocalDateTime dateTime = LocalDateTime.now();
```



示例

```
LocalDate date = LocalDate.now();
LocalDateTime dateTime = LocalDateTime.now();
System.out.println(date);
System.out.println(dateTime);
```

输出

```
2026-05-24
2026-05-24T11:27:59.878
```



## 用工具类格式化 

工具类：DateTimeFormatter

示例

```
DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy年MM月dd日 HH:mm:ss");
String data = dateTime.format(formatter);
System.out.println(data);
```

输出

```
2026年05月24日 11:27:59
```



注

HH：若为大写（HH）为24小时制，若为小写（hh）为12小时制





## 时间运算

### 天数的加减

加

.plusDays（天数）

减

.minusDays（天数）



示例

```
#date = 2026-05-24
System.out.println(date.plusDays(5));
System.out.println(date.minusDays(5));
```

输出

```
2026-05-29
2026-05-19
```



### 差了多少天

Period：只管日期、不管时分秒



```
Period period = Period.between(date, date1);//5天
System.out.println(period);
```

输出

```
P5D
```

`P`：时间段标识

P3Y4M6D => 3 年 4 月 6 天



获得年/月/日

period.getYears()

period.getMonths() 

period.getDays()



示例

```
Period period = Period.between(date, date1);//5天
System.out.println(period.getDays());
System.out.println(period.getMonths());
System.out.println(period.getYears());
```

输出

```
5
0
0
```



### 比较

isAfter()：判断一个日期 / 时间 是否 在 另一个日期 / 时间 之后

isBefore() ： 判断一个日期 / 时间 是否 在 另一个日期 / 时间 之前

isEqual() ：判断一个日期 / 时间 是否 与另一个日期 / 时间 相等

都返回布尔值



示例

```
boolean a = date.isAfter(date1);  // 24  29
boolean b = date.isBefore(date1);
boolean c = date.isEqual(date1);
System.out.println(a);
System.out.println(b);
System.out.println(c);
```

输出

```
false
true
false
```
