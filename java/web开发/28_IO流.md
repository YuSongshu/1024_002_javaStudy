## 分类

- Input ：输入，读数据，（读取）
- Output：输出，写数据，（推送）

![IO流体系](.\辅助图片_视音频等资料\28\IO流体系.png)

四大流：

- 字节输入流：把磁盘（网络）中的数据，按照一个一个字节的单位读取到程序中 
- 字节输出流：把程序中的数据，按照一个一个字节的单位推送到 磁盘或网络中
- 字符输入流：把磁盘（网络）中的数据，按照一个一个字符的单位读取到程序中 
- 字符输出流：把程序中的数据，按照一个一个字符的单位推送到 磁盘或网络中

##### 方法一：一次读一个字节

```
int i = stream.read();          // 返回 int（0~255），读完返回 -1
// i存的是ASCII 码
System.out.println((char) i);   // 所以需强转 char 才能看到字符
```

##### 方法二：一次读入字节数组（推荐）

```
byte[] bytes = new byte[3];     // 一次性读取 3个字节，如果只要两个字节则最后会有一个乱码
int i4 = stream.read(bytes);    // 实际读到的字节数放入返回值
System.out.println(new String(bytes));
```

##### 方法三：循环读取全部内容（生产写法）

```
int size;                          // 记录本次实际读了多少字节
byte[] bytes1 = new byte[1024];    // 一次最多读 1024 字节

// read 返回 -1 表示文件读取完毕，作为循环结束条件

while ((size = stream.read(bytes1)) != -1) {
    System.out.println(size);
    // 从索引 0 开始，只转 size 个字节，避免末尾残留脏数据
    System.out.println(new String(bytes1, 0, size));
}
```



注：

| 方法              | 读取单位           | 返回值含义             |
| ----------------- | ------------------ | ---------------------- |
| `read()`          | 1 个字节           | 字节值 (0~255) /-1     |
| `read(byte[] b)`  | 字节数组缓冲区     | 本次读到的字节个数 /-1 |
| `read(b,off,len)` | 字节数组，指定区间 | 本次读到的字节个数 /-1 |

返回-1代表读完了

#### 输出流

声明:

```
// 第二个参数 true = 追加模式；false 或省略(默认) = 覆盖模式
InputStream 对象名 = new FileOutputStream("地址",true);

File file对象 = new File("地址");
OutputStream stream = new FileOutputStream(file对象, true);
```

示例

```
File f = new File("09\\src\\redme.txt");
OutputStream stream = new FileOutputStream(f, true);
```





```
File f = new File("09\\src\\redme.txt");
OutputStream stream = new FileOutputStream(f, true);

stream.write(97);                    // 写入单个字节，97 = 字符 'a'
stream.write("\r".getBytes());       // 写入回车换行
stream.write("你好你爱护哦".getBytes()); // 字符串先转字节数组

stream.flush();   // 刷新，强制推送缓冲区数据
stream.close();   // 关闭资源（关闭前通常要 flush）
```

注：操作纯文本字符文件时，不建议用字节流——中文可能被截断成半个字符，建议用字符流。





##### write()方法

它和 `read()` 的返回值是配套的：`read()` 读出 `0~255` 的 int（文件末尾 `-1`），`write(int b)` 写入 `0~255` 的低 8 位。

```
out.write(97);        // 写入字节 97，对应 ASCII 字符 'a'
out.write(0x61);      // 同上，十六进制 97
out.write('a');       // 同上，char 会自动转 int

out.write(300);       // 300 = 0b1_0010_1100，低8位 0010_1100 = 44
                      // 写入的是 44（字符 ','），不是 300
out.write(-1);        // -1 的低8位是 0xFF = 255，写入字节 0xFF
```

| 方法                              | 写入内容                                 | 典型用途             |
| --------------------------------- | ---------------------------------------- | -------------------- |
| write(int b)                      | **1 字节**                               | 单字节写入、写标记位 |
| write(byte[] b)                   | 整个数组                                 | 已知数据是完整缓冲   |
| write(byte[] b, int off, int len) | 数组一部分,从数组下标`off` 写 `len` 字节 | **文件复制（推荐）** |

注：

len 溢出会报错

## 拓展

### 缓存流与转换流

| 类                     | 包装谁         | 方向 |
| ---------------------- | -------------- | ---- |
| `BufferedInputStream`  | `InputStream`  | 输入 |
| `BufferedOutputStream` | `OutputStream` | 输出 |
| `BufferedReader`       | `Reader`       | 输入 |
| `BufferedWriter`       | `Writer`       | 输出 |

|              | 缓冲流                          | 转换流                                  |
| ------------ | ------------------------------- | --------------------------------------- |
| 核心作用     | **提速**（减少 I/O 次数）       | **桥接 + 指定编码**                     |
| 解决的痛点   | 读写太慢                        | 字节↔字符、中文乱码                     |
| 能否指定编码 | 不能（继承底层）                | **能**（构造器传 Charset）              |
| 典型搭配     | `BufferedReader` + `FileReader` | `InputStreamReader` + `FileInputStream` |

示例

```
Reader r = new InputStreamReader(new FileInputStream("data.txt"), StandardCharsets.UTF_8);
BufferedReader br = new BufferedReader(r);   // 转换 + 缓冲 两层包装

String line;
while ((line = br.readLine()) != null) {
    System.out.println(line);
}
br.close();
```
