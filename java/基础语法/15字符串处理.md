#### 比较大小

字符串1.compareTo(字符串2)

1.数字

```
Integer x = 5;
Integer y = 9;
x.compareTo(y);  // 负：5 < 9
y.compareTo(x);  // 正：9 > 5
```



2.String 字符串

按ASCII 字典顺序逐字符比较

若前面都一样、长度不同：返回**长度差值**

str>str1  返回正数

str<str1  或 字符串第一个为空格  	返回负数

```
String str = "我爱您中国";

```

#### 第一次出现的位置

a.indexOf(b)

b在a中第一次出现的位置

```
String a = "我爱您中国爱您中国爱您中国";
String b = "中国";
int  wz =  a.indexOf(b);
System.out.println(wz);		//输出 3
```



##### 重载

 a.indexOf(b,下标)

从下标开始

```
String a = "我爱您中国爱您中国爱您中国";
String b = "中国";
int  wz =  a.indexOf(b,4);
System.out.println(wz);		//输出 7
```



#### 最后一次出现的位置

### 分割  

.split("符号")

```
String str = "张-三@李-四@王-五";
String [] data = str.split("@");
System.out.println(data.length);
System.out.println(data[0].split("-")[0]+data[0].split("-")[1]);
System.out.println(data[1]);
System.out.println(data[2]);
```

输出

```
3
张三
李-四
王-五

```





### 替换

```
String str = "张-三@李-四@王-五";
String newStr = str.replaceAll("@", " ").replace("-", "");
System.out.println(newStr);
```

输出

```
张三 李四 王五
```

注

**replace**：字面量替换，不识别正则

**replaceAll**：正则表达式替换，匹配正则规则

特殊字符用 replaceAll 会出错

正则特殊字符：`.` `*` `+` `?` `\` `[]` `()` 等
