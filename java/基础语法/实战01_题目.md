    zt TINYINT DEFAULT 1,
    FOREIGN KEY (cid) REFERENCES class(cid)

    id INT PRIMARY KEY AUTO_INCREMENT,
    sid INT NOT NULL,
    old_cid INT NOT NULL,
    new_cid INT NOT NULL,
    old_sname VARCHAR(50) NOT NULL, 
    new_sname VARCHAR(50) NOT NULL, 
    old_zy VARCHAR(50), 
    new_zy VARCHAR(50),

    new_zt TINYINT,
    FOREIGN KEY (sid) REFERENCES student(sid),
    FOREIGN KEY (old_cid) REFERENCES class(cid),
    FOREIGN KEY (new_cid) REFERENCES class(cid)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE score (
    scid INT PRIMARY KEY AUTO_INCREMENT,
    sid INT NOT NULL,
    kc VARCHAR(50) NOT NULL,
    cj DECIMAL(5,2),
    xf DECIMAL(5,3),
    FOREIGN KEY (sid) REFERENCES student(sid)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

### 检查型异常

用了 JDBC 这些方法：

- `Class.forName(...)`
- `getConnection(...)`
- `executeQuery(...)`
- `executeUpdate(...)`

这些**自带 “检查型异常”**，Java 强制要求：

要么：方法后面写 `throws Exception`

要么：方法里面写 `try-catch`

即

```
public void addClass(Statement stmt) throws Exception {
	System.out.print("输入班级名：");
    String cname = scan.nextLine();
    String sql = "INSERT INTO class(cname) VALUES('"+cname+"')";
    stmt.executeUpdate(sql);
    System.out.println("添加成功！");
}
```

```
public void addClass(Statement stmt) {
    try {
        System.out.print("输入班级名：");
        String cname = scan.nextLine();
        String sql = "INSERT INTO class(cname) VALUES('"+cname+"')";
        stmt.executeUpdate(sql);
        System.out.println("添加成功！");
    } catch (Exception e) {
        e.printStackTrace();
    }
}
```

调用封装方法时，必须把 Statement 对象传给它，它在里面用



### String.format() 格式化输出

内容长短不一样就会错位，控制台无法自动对齐、

最佳解决方案：用 `String.format()` 格式化输出

语法

```
String.format("格式字符串", 参数1, 参数2, 参数3...);
```

示例

```
// 表头（固定宽度）
System.out.println(String.format("%-8s %-8s %-12s %-6s", "编号", "姓名", "专业", "状态"));

// 数据行
while (rs.next()) {
    int zt = rs.getInt("zt");
    String zt2 = (rs.wasNull() || zt == 0) ? "休学" : "在读";
    
    // 格式化输出，自动对齐
    System.out.println(String.format("%-8d %-8s %-12s %-6s",
        rs.getInt("sid"),
        rs.getString("sname"),
        rs.getString("zy"),
        zt2));
}
```

注：

`%-8s`：字符串左对齐，占 8 个字符宽度

`%-8d`：整数左对齐，占 8 个字符宽度

`%10s`:  字符串右对齐，占10个字符

`%8d `:   整数右对齐,占 8 个字符宽度

 居中对齐（Java 原生不支持）

常用占位符

| 符号 | 作用                   | 示例       |
| ---- | ---------------------- | ---------- |
| `%s` | 字符串                 | "姓名"     |
| `%d` | 整数（int/long）       | 100        |
| `%f` | 浮点数（float/double） | 99.9       |
| `%b` | 布尔值                 | true/false |
| `%t` | 日期时间               | 2025-12-29 |



如果输出的内容实际长度超过了指定的格式化宽度

结果**绝对不会截断**，它会**自动溢出**

解决方案

格式化之前手动截断

```
// 假设专业最多显示 8 个字符
String zy = rs.getString("zy");
// 如果长度超过 8，就截取前 8 个字符并加省略号
String displayZy = zy.length() > 8 ? zy.substring(0, 8) + "..." : zy;

// 输出时限制宽度（此时不用担心溢出，因为我们已经处理过了）
System.out.println(String.format("%-8s", displayZy));
```





### 分隔符截取字符串

语法

```
SUBSTRING_INDEX(str, delimiter, count)
```

```
SUBSTRING_INDEX(c.cname, '年', 1) AS old_grade_num
```



| 参数        | 说明       | 本例取值  | 作用                                              |
| ----------- | ---------- | --------- | ------------------------------------------------- |
| `str`       | 原始字符串 | `c.cname` | 班级名称（如 “2 年 1 班”）                        |
| `delimiter` | 分隔符     | `'年'`    | 截取边界标识（中文 “年”）                         |
| `count`     | 截取计数   | `1`       | 正数：从左往右取第 `count` 个分隔符**之前**的内容 |



应用

```
SELECT   s.cid old_cid,SUBSTRING_INDEX(c.cname,'年',1)+0 grade FROM student s   JOIN class c ON s.cid=c.cid WHERE s.sid=1; 
```

字符串 + 0 会自动尝试转为数值





### 1248报错（派生表的使用）

中间这层派生表要起别名，否则MySQL 不识别这个临时表，直接报错1248

示例

 错误示范

```
SELECT sid, COUNT(*) '变动次数' FROM student_change GROUP BY sid HAVING COUNT(*) = ( SELECT MAX(cnt) FROM (SELECT COUNT(*) cnt FROM student_change GROUP BY sid))
```

订正

派生表起别名（`... AS temp`）

```
SELECT sid, COUNT(*) '变动次数' FROM student_change GROUP BY sid HAVING COUNT(*) = ( SELECT MAX(cnt) FROM (SELECT COUNT(*) cnt FROM student_change GROUP BY sid) AS temp)
```
